# Requisitos do Projeto

Abaixo estão listados os requisitos funcionais (RF) e não funcionais (RNF) do projeto, juntamente com suas respectivas prioridades, conforme definido no documento de planejamento inicial.

| Descrição do Requisito | Tipo de Requisito | Prioridade |
| --- | --- | --- |
| Deve suportar 2 jogadores simultâneos | RF | Alta |
| Geração na tela de sequência de gestos a serem repetidos pelos jogadores | RF | Alta |
| Dedos dos jogadores sendo capturados pelas câmeras | RF | Alta |
| Barra de vida do oponente diminuindo conforme se acerta as sequências de gesto | RF | Alta |
| Geração pseudo aleatória da sequência | RNF | Baixa |
| Exibir ambiente e personagens batalhando na interface do jogo | RNF | Média |
| Mecânica de especiais | RNF | Alta |
| Exibir mensagem de vitória ao final da partida | RF | Média |
